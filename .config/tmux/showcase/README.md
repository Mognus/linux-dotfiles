# Tmux

Tmux keeps terminal sessions alive.

## Keybinds

- `Alt+T` - new tmux window
- `Alt+D` - close current tmux window
- `Ctrl+Alt+T` - split pane right in current directory
- `Ctrl+Alt+V` - split pane down in current directory
- `Ctrl+Alt+D` - close current pane
- `Alt+J/K` - previous/next tmux window
- `Alt+Shift+J/K` - move current tmux window left/right
- `Ctrl+Alt+H/J/K/L` - switch pane left/down/up/right

## Does

- Persistent terminal sessions
- Named workspaces for projects or services
- Vi-style copy mode

## Workflow

Use named sessions for separate projects or services, and attach back to long-running work instead of rebuilding terminal state.
